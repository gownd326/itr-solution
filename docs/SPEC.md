## 1. 프로젝트 개요 (한눈에 보기)

### 프로젝트 개요
- **목적**: 기존 회사 홈페이지(http://itrsolution.helloweb.co.kr/)를 최신 트렌드에 맞춘 모던하고 신뢰감 주는 기업 소개 및 문의 사이트로 리모델링합니다.
- **핵심 가치**: 전문성 강조, 빠른 로딩 속도, 모바일 반응형 디자인, 간편한 문의 접수
- **대상 사용자**: IT 솔루션 도입을 검토 중인 기업 고객, 파트너사

### 주요 목표
1. 최신 웹 표준을 준수하는 깔끔한 UI/UX 디자인 적용
2. 주요 서비스 및 포트폴리오 정보를 직관적으로 전달
3. 고객 문의(견적/상담) 기능 고도화

## 2. 사용자와 사용 시나리오

### 주요 사용자 및 시나리오

| 사용자 | 주요 행동 | 시나리오 | 수용 기준 |
| --- | --- | --- | --- |
| **일반 방문자** | 회사 소개 및 서비스 확인 | 메인 페이지 접속 후 제공 중인 솔루션 목록을 확인한다. | 3초 이내 메인 로딩 완료, 모바일에서 가로 스크롤 없음 |

## 4. 화면과 주소(URL) 구성

### 화면 및 URL 구조

| 경로 (URL) | 화면명 | 주요 UI 요소 |
| --- | --- | --- | 
| `/` | 메인 페이지 | 히어로 섹션, 서비스 요약, 고객사 로고, CTA(행동 유도) 버튼 |

## 5. 데이터 모델

### 데이터 모델 (Supabase)

#### `inquiries` (문의 접수 테이블)
- `id` (uuid, Primary Key, 기본값 `gen_random_uuid()`)
- `created_at` (timestamp with time zone, 기본값 `now()`)
- `name` (text, 필수)
- `company` (text, 선택)
- `phone` (text, 필수)
- `email` (text, 필수)
- `message` (text, 필수)
- `status` (text, 기본값 `'unread'`, 값: `unread`, `read`, `completed`)

#### 행 수준 보안 (RLS) 정책
- `inquiries` 테이블: 누구나(anon) `INSERT` 가능 (문의 등록용), 인증된 관리자(`authenticated`)만 `SELECT`, `UPDATE` 가능.

## 10. 테스트 계획

### 테스트 계획 및 시나리오

| 테스트 ID | 테스트 항목 | 사전 조건 | 테스트 절차 (Given / When / Then) | 기대 결과 |
| --- | --- | --- | --- | --- |
| T-01 | 문의 폼 제출 | `/contact` 접속 | **Given** 문의 페이지에 접속해 있다.<br>**When** 필수 입력값(이름, 연락처, 이메일, 내용)을 입력하고 제출 버튼을 누른다.<br>**Then** 성공 메시지가 노출되고 Supabase `inquiries` 테이블에 데이터가 적재된다. | 데이터 정상 저장 및 완료 팝업 노출 |
| T-02 | 문의 폼 유효성 검사 | `/contact` 접속 | **Given** 문의 페이지에 접속해 있다.<br>**When** 필수값을 비운 채 제출 버튼을 누른다.<br>**Then** 브라우저 유효성 검사 또는 에러 메시지가 뜬다. | 제출 차단 및 에러 안내 |
| T-03 | 관리자 인증 및 조회 | 관리자 비밀번호 숙지 | **Given** `/admin/inquiries`에 접속한다.<br>**When** 설정된 관리자 비밀번호를 입력하여 인증한다.<br>**Then** DB에 저장된 문의 목록 테이블이 정상 렌더링된다. | 문의 내역 리스트 출력 |
| T-04 | 스모크 테스트 | 배포 완료 상태 | **Given** 사이트가 배포되어 있다.<br>**When** `/`, `/services`, `/contact` 경로로 접속한다.<br>**Then** HTTP 200 상태 코드로 페이지가 렌더링된다. | 에러 없는 페이지 로딩 |
